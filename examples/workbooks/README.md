`tests/fixtures/highcharts-options.ts` with Highcharts 13.1.1. Each file holds a `Chart` sheet with a
native Excel chart and a `Data` sheet the chart references. They are kept here so the manual Excel
QA in `docs/manual-qa.md` can start without running the test suite. Regenerate with `pnpm test`
and copy from `tests/output/export/v13/`.

`@office-kit/xlsx`. They have not been opened in Microsoft Excel in the development environment.
